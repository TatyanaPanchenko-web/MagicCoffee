# Magic coffee

Учебный проект на React JS — мини-приложение для заказа горячих напитков. Реализованы регистрация и авторизация пользователя, выбор напитков и работа с корзиной. В проекте используется Redux Toolkit для централизованного управления состоянием приложения и TypeScript для строгой типизации компонентов, состояния и логики, что повышает надежность и удобство разработки.
